# Edition 01: Foundations — Week of October 5, 2026

The companion write-up for [Awesome Agent Skills](../README.md). The living catalog stays in the root README; this file keeps the narrative, cost notes, sources, and honorable mentions for the week.

**What this is:** installable skill packs and official collections with real repos and docs.  
**What this isn't:** one-off prompt snippets or unverified catalogs that rehost others without adding signal.

> Install tip: most GitHub packs work with `npx skills add owner/repo` ([skills.sh](https://www.skills.sh/)). Prefer official orgs. Scan untrusted skills before install ([SkillSpector](https://github.com/NVIDIA/SkillSpector)).

---

## Why Foundations

A first edition has one job: set the floor. These packs change how an agent works, not just what it knows. Read in order, they trace a single working session: learn the format, find the right skill, plan, challenge the plan, build to a standard, reach the web, and audit what shipped.

The seven featured tracks are summarized in the root README under [This week](../README.md#this-week). The sections below expand them with cost notes and related picks.

---

## Standards and discovery

- [agentskills.io Specification](https://agentskills.io/specification) — The open `SKILL.md` standard (name and description, progressive disclosure, scripts, references, assets). Free docs.
- [anthropics/skills](https://github.com/anthropics/skills) — Anthropic's official open skill examples plus `skill-creator`; the reference pattern for document, design, MCP, and testing skills. Free and open. Org: Anthropic.
- [find-skills](https://www.skills.sh/vercel-labs/skills/find-skills) — Lets the agent search and install skills mid-session from the open ecosystem (`npx skills find` / `add`). Free. Author: Vercel Labs.

## Coding workflows

- [obra/superpowers](https://github.com/obra/superpowers) — Full agentic methodology pack: brainstorm, plans, TDD, parallel subagents, and verification before shipping. Free. Author: Jesse Vincent (obra).
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) — 20+ production engineering workflows (review, APIs, performance, observability, shipping) with gates and anti-rationalization tables. Free. Author: Addy Osmani. Site: [skills.addy.ie](https://skills.addy.ie).
- [mattpocock/skills](https://github.com/mattpocock/skills) — "Skills for real engineers," topped by [grill-me](https://www.skills.sh/mattpocock/skills/grill-me) (relentless plan stress-testing), plus TDD, architecture, and triage. Free. Author: Matt Pocock.
- [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) — Vercel's official React and Next.js patterns: best practices, composition, web-design guidelines, React Native. Free. Org: Vercel Labs.
- [expo/skills](https://github.com/expo/skills) — Official Expo and EAS skills: native UI, Router, deployment, CI/CD, upgrades. Free. Org: Expo.

## Browser and testing

- [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser) — Browser automation CLI and skills so agents can navigate, fill forms, extract, and screenshot without custom scripts. Free CLI; docs: [agent-browser.dev/skills](https://agent-browser.dev/skills). Org: Vercel Labs.
- [firecrawl/cli](https://github.com/firecrawl/cli) — Agent skills for scrape, search, crawl, and browser interact via Firecrawl. Free skill pack; **Firecrawl API usage may be paid**. Org: Firecrawl.
- [anthropics/webapp-testing](https://officialskills.sh/anthropics/skills/webapp-testing) — Playwright-based local webapp testing skill from Anthropic's examples. Free and open.

## Security and platforms

- [trailofbits/skills](https://github.com/trailofbits/skills) — Security-research pack: static analysis, Semgrep rules, differential review, insecure defaults, smart-contract tooling. Free. Org: Trail of Bits.
- [cloudflare/skills](https://github.com/cloudflare/skills) — Teach agents Workers, Durable Objects, Wrangler, Agents SDK, and platform best practices. Free. Org: Cloudflare.
- [supabase/agent-skills](https://github.com/supabase/agent-skills) — Postgres and Supabase best practices (including RLS and performance-oriented guidance) for agent-written data code. Free. Org: Supabase.
- [neondatabase/agent-skills](https://github.com/neondatabase/agent-skills) — Neon Serverless Postgres skills (branching, egress, claimable DB patterns). Free. Org: Neon.

## Writing and design

- [Anthropic document skills (pptx / xlsx / docx / pdf)](https://docs.anthropic.com/en/docs/agents-and-tools/agent-skills/overview) — Pre-built Office and PDF creation and editing skills on Claude API and claude.ai. Free to use with Claude; **custom uploads on claude.ai need Pro/Max/Team/Enterprise plus code execution**.
- [anthropics/frontend-design](https://officialskills.sh/anthropics/skills/frontend-design) — High-signal frontend and UI skill; consistently near the top of skills.sh installs. Free and open.
- [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) — Full SaaS marketing stack as skills: SEO audit, CRO, copywriting, launch, pricing, ads. Free. Author: Corey Haines.
- [remotion-dev/skills](https://github.com/remotion-dev/skills) — Programmatic video-with-React agent skills from the Remotion team. Free. Org: Remotion.
