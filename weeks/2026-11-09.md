# Edition 06: Teach and take apart — Week of November 9, 2026

The companion write-up for [Awesome Agent Skills](../README.md). The living catalog stays in the root README; this file keeps the narrative, cost and safety notes, the week's platform news, and honorable mentions.

**What this is:** nine additions to the catalog, seven of them featured, all with real repos and docs.  
**What this isn't:** a ranking by stars. Two picks are older repos that the week made more relevant; the rest are new or newly released since November 2.

> Install tip: most packs here install with `npx skills add owner/repo` ([skills.sh](https://www.skills.sh/)) or `gh skill install owner/repo` (GitHub CLI 2.90.0 or later). EGM and champion-kit install as Claude Code plugins, Genesis Skills ships an `unpack.sh`, and Jane Street's tutor is copied into your skills folder by hand.

---

## Why teach and take apart

The repos that climbed fastest this week share a habit: they understand something before they produce anything. Jane Street's tutor runs a diagnostic before it teaches a single fact. Caldo's refactor skill writes down every problem before it changes a line. rea-video breaks a clip into shots before it suggests a remake. Google's Elephant-Goldfish Model separates the agent that knows everything from the reviewers that know nothing, so the draft gets read the way a stranger would read it.

The other half of the week was teaching agents, not people. Microsoft published builder skills for its Agent Framework, the U.S. Department of Energy released Genesis Agent Skills for scientific workflows, and Anthropic added a plugin for the person who teaches a team to use Claude Code. Platforms are now shipping skills alongside their docs, so agents learn the platform's way of building instead of guessing.

## Featured tracks

### 1. Tutoring: [janestreet/agent_skills](https://github.com/janestreet/agent_skills)

Jane Street's first public skills repo, created November 3, passed 1,800 stars in its first week. It holds one skill, `socratic-tutor`, which turns an agent into a strict personal tutor. Say "teach me", "quiz me", or "drill me" and it breaks the topic into 4 to 10 subskills, runs a short diagnostic, and shows a skill map with levels from 0 (unaware) to 5 (can teach it). Then it teaches mostly by asking, one question at a time, with spaced review and a final assessment. A guard stops it from turning a one-off "explain X" into a quiz. Copy the `socratic-tutor` folder into your agent's skills directory, or paste the `SKILL.md` into any chatbot. Free, MIT.

### 2. Design review: [google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model)

Google's EGM plugin gained about 5,700 stars this week, and v0.1.1 shipped November 6. The idea is in the name. The elephant holds your project context and drafts a specification section by section (`egm-brainstorm`, `egm-draft`). Goldfish reviewers then read the draft and its references without the earlier conversation (`egm-review`, `egm-review-loop`), and you resolve the findings and approve the design before any code is written. `egm-bootstrap` documents an existing codebase and `egm-drift-report` compares a spec with what was built. v0.1.1 adds a TRIZ inventive reviewer and experimental Cursor, OpenCode, and GitHub Copilot adapters. Install in Claude Code with `claude plugin marketplace add google/elephant-goldfish-model`, then `claude plugin install egm@egm`; Codex and Antigravity commands are in the README, and the [website](https://egm.dev) has the docs. Free, Apache-2.0. **Note:** the project says the release is not yet ready for stable-release claims.

### 3. Teardown: [JuneYaooo/rea-video](https://github.com/JuneYaooo/rea-video)

The fastest-rising skill repo of the week, at more than 5,000 stars ten days after it was created. Give it a video and it decides, shot by shot, whether each part was filmed, AI-generated, or coded. You get a one-line summary, a remake plan split into what to film, what to generate, and what to code, and a `report.html` with per-shot frames, evidence, prompts, camera and lighting notes, and an audio breakdown. Tell Claude Code or Codex to install it from the repo URL, or run `bash scripts/install_skill.sh` by hand. Free, Apache-2.0. **Requirements:** ffmpeg and Python 3.10 or later. **Cost note:** it works without a model key, and an optional Gemini or Doubao video model makes the calls more accurate at that provider's prices.

### 4. Untangle: [caldoai/skills](https://github.com/caldoai/skills)

Caldo's repo passed 1,000 stars on the strength of one skill, `untangle-codebase`. It asks one question of every part of a codebase: should these pieces change together? It writes down every place the answer is wrong in three groups (hidden links, needless links, and surplus) plus every special case, all before it changes anything. Then it refactors the whole codebase to the end, so agents read less per change, break less without noticing, and find root causes faster. It optionally removes comments that restate code and tests that would never catch a real bug. Install with `npx skills add caldoai/skills --skill untangle-codebase`. The skill only runs when you call it by name. Free, MIT. **Safety note:** this is a whole-codebase refactor, so run it on a branch and review the decision log it writes.

### 5. Builder skills: [microsoft/agent-framework](https://github.com/microsoft/agent-framework/tree/main/skills)

Microsoft [announced](https://devblogs.microsoft.com/agent-framework/give-your-coding-agent-a-head-start-with-microsoft-agent-framework-skills-for-net-and-python/) two skills on November 4: `agent-framework-builder-python` and `agent-framework-builder-dotnet`. They're decision guidance, not a copy of the docs. They help a coding agent choose between a plain agent, a harness agent, and a workflow, pick extension points and hosting patterns, and then link to current Microsoft Learn pages for the implementation. Preview with `gh skill preview microsoft/agent-framework agent-framework-builder-python@main`, then install with `gh skill install`, or use `npx skills add microsoft/agent-framework --skill agent-framework-builder-python`. Free, MIT. **Note:** keep the `@main` ref until a tagged release includes the skills.

### 6. Science: [AI-ModCon/genesis-skills](https://github.com/AI-ModCon/genesis-skills)

The U.S. Department of Energy [announced](https://www.energy.gov/science/articles/genesis-agent-skills-release-support-innovation-across-genesis-mission) Genesis Agent Skills this week, the first public release from its ModCon program for the Genesis Mission. The catalog groups skills by domain: HPC, literature search, plasma simulation, scientific data and metadata, agent evaluation, AI safety, and multi-agent systems. Fermilab contributed a skill that turns a scientific machine learning project into a standard benchmark. Clone the repo and run `./unpack.sh --target "$HOME/.agents/skills"` to flatten the skills into place, or link only the bundled `skill-search` skill and let the agent find the rest on demand. Free, BSD-2-Clause. **Note:** the DOE release points to a [GitLab copy](https://gitlab.osti.gov/genesis/genesis-skills), which is a read-only mirror; issues and pull requests go to GitHub. Some skills depend on HPC access or other outside tools.

### 7. Adoption: [anthropics/claude-plugins-official: champion-kit](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/champion-kit)

Added to Anthropic's official plugin marketplace on November 6, champion-kit is for the person on a team who helps everyone else start with Claude Code. It builds on the public [champion kit](https://code.claude.com/docs/en/champion-kit) page. `/champion-kit:hackathon` plans a hack day from your real backlog, `office-hours` sets up sessions and writes up the answers, `patterns` finds repeated fixes worth turning into rules or skills, and `maturity` scores your organization with evidence and writes a shareable HTML report. The plugin is only skills and one read-only helper agent, with no hooks and no MCP servers. Install with `claude plugin install champion-kit@claude-plugins-official`. Free, Apache-2.0. **Safety note:** the commands ask before they read git history, chats, or transcripts, or write a file, but in auto mode Claude Code does not stop file writes. Use manual mode if you want a prompt for every write.

## Also added to the catalog

### Writing and design

- **[Nutlope/hallmark](https://github.com/Nutlope/hallmark)** - Together AI's anti-slop design skill, now past 50,000 stars, and earlier editions missed it. Version 2 (October 22) brought 50 themes, pages built around what the visitor came to do, 755 openly licensed photos, and `redesign` and `audit` modes. Every build is linted in a real browser at eight widths, and a fresh-context reviewer gets the last word. Install with `npx skills add nutlope/hallmark -g`. See the [themes](https://www.usehallmark.com). Free, MIT.
- **[patch-gg/pixelfx](https://github.com/patch-gg/pixelfx)** - 244 pixel art effects (fire, explosions, weather, UI, pickups, and more), each one a small piece of code you can recolor, mirror, and export as sprite sheets for Godot, Unity, or Phaser. The bundled Claude Code skill makes new effects the way Hugo Duprez [describes](https://www.spritefusion.com/blog/how-to-make-good-pixel-art-effects-with-claude): draft, render a contact sheet, look at it, refine. Install with `/plugin marketplace add patch-gg/pixelfx`, then `/plugin install pixelfx@pixelfx`. Browse the [gallery](https://patch-gg.github.io/pixelfx/). Free, MIT. Needs Node 18 or later.

## Platform news this week

- **Platforms ship skills with their docs.** Microsoft's Agent Framework builder skills (November 4) and DOE's Genesis Agent Skills (announced this week) join the official vendor packs already in the catalog. Both point agents at current documentation instead of repeating it.
- **Fresh eyes is now a pattern.** EGM's goldfish reviewers, Hallmark's final reviewer, MiniMax's `independent-review` from last week, and [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill), which gained more than 10,000 stars this week, all give the last word to a reviewer that never saw the conversation that made the work.

## Honorable mentions

Promising, but either too new, too narrow, or not yet proven enough for the catalog.

- **[penligent/AIPentest_Skills](https://github.com/penligent/AIPentest_Skills)** - 159 `SKILL.md` skills for authorized penetration testing, published November 9 with validators: vulnerability verification, API review, workflow, platform review, and 100 CVE exposure checks. It's one day old with no community track record yet, so we'll check back.
- **[scenario-labs/skills](https://github.com/scenario-labs/skills)** - Image, video, audio, and 3D skills through the Scenario MCP, plus expert teams for Blender, Maya, Unreal, and Unity. Well built, but the core skills depend on a paid API.
- **[manhquydev/flow-skill](https://github.com/manhquydev/flow-skill)** - A six-gate build harness meant to stop agents from claiming work is done when it isn't. A good idea, but still small.

## Left out on purpose

None of them cleared the inclusion bar. Preview before you install (`gh skill preview`), and scan third-party packs ([NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector)).
