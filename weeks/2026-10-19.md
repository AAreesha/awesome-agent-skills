# Edition 03: Ambition and reach — Week of October 19, 2026

The companion write-up for [Awesome Agent Skills](../README.md). The living catalog stays in the root README; this file keeps the narrative, cost and safety notes, the week's platform news, and honorable mentions.

**What this is:** nine additions to the catalog, seven of them featured, all with real repos and docs.  
**What this isn't:** a list of the week's newest repos. Several picks are months old; they made the cut because the week made them more relevant, not because they were fresh.

> Install tip: most packs here install with `npx skills add owner/repo` ([skills.sh](https://www.skills.sh/)). pstack, AWS, Shopify, and Blender also ship as Claude Code plugins; each README gives the exact command.

---

## Why ambition and reach

On October 13, Felix Rieseberg, an engineering lead on Claude at Anthropic, published [How to be more ambitious: a tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/). His point is that most people use a model at the size of the task they typed. Instead of fixing one crash, ask it to keep the app crash-free. Instead of a markdown table, ask for what the best expert would do with the raw data. It was the most-shared piece on working with models all week.

Ambition without rigor just produces bigger slop, so this edition pairs the two. Track 1 turns the tutorial into a skill, and track 2 is the verification method one Cursor engineer uses every day. Tracks 3 to 7 extend what an agent can reach: compiled binaries, whole architectures, real checkouts, managed cloud services, and 3D scenes.

## Featured tracks

### 1. Ambition: [robonuggets/be-ambitious](https://github.com/robonuggets/be-ambitious)

Turns Felix Rieseberg's tutorial into steps an agent follows. It finds the goal beyond the goal, picks the kinds of ambition that fit (altitude, depth, or range), writes the bigger plan, lists the data and access that plan needs, and rewrites your prompt so it ends with an outside check and a clear pass condition. The ideas are Felix's, and the repo says so. Free, MIT. New on October 17 and still small, so it's included for substance rather than traction.

### 2. Rigor: [cursor/plugins: pstack](https://github.com/cursor/plugins/tree/main/pstack)

Lauren Tan (poteto), who works on Cursor and on the React Compiler, publishes the skills she uses every day: restate the problem, plan, dig in, and verify, all run through one `poteto-mode` entry point that uses different models for different steps. Install it in Cursor with `/add-plugin pstack`, or in Claude Code from the `cursor/plugins` marketplace. Free, MIT. It got a lot of attention this week, and many community ports for other harnesses exist. Use the upstream version.

### 3. Understanding: [morluto/rea](https://github.com/morluto/rea)

REA (Reverse Engineer Anything) is one MCP server plus a skill for studying how software works, from app behavior and runtime traces down to native binaries. You set it up with `npx rea-agents setup`. Free, MIT. **Safety note:** REA's own README warns that repos with similar names and copied READMEs are not official. Install only from `morluto/rea`, [rea.tools](https://rea.tools/), or the `rea-agents` npm package, and only reverse-engineer software you're allowed to analyze.

### 4. Explanation: [tt-a1i/archify](https://github.com/tt-a1i/archify)

Describe a system, a plan, or a repo, and Archify gives you an interactive HTML diagram you can explore, trace, and restyle. When it reads a repo, the diagram nodes link back to source files. Works with Cursor, Claude Code, Codex CLI, and OpenCode via `npx skills add tt-a1i/archify -g`. Free, MIT. The README lists sponsors and third-party hosted services, but those are separate from the open skill.

### 5. Commerce: [Shopify/shop](https://github.com/Shopify/shop)

Shopify's official Shop skill, released with [Shop MCP](https://shopify.dev/changelog/posts/add-shopping-and-shop-pay-checkout-to-any-agent-with-shop-mcp) on October 13. It lets an agent search Shopify Catalog, build carts, open a checkout with the store that sells the item, and track orders. Search needs no API key. To finish a purchase, the shopper confirms the total and payment method before the agent calls `complete_checkout`. Setup guide: [shop.dev](https://shop.dev/docs/connect). Free, MIT. **Money note:** the agent can place real orders, so keep the confirmation step on.

### 6. Cloud: [aws/agent-toolkit-for-aws](https://github.com/aws/agent-toolkit-for-aws)

AWS now calls this toolkit the single supported way to give agents AWS skills, replacing the earlier AWS Labs skills and plugins. Two additions landed this week: the [AWS AI/ML skill](https://aws.amazon.com/about-aws/whats-new/2026/10/bring-sagemaker-ai-expertise-to-your-coding-agent/) for SageMaker AI training, tuning, and deployment (October 13), and four [Amazon MWAA skills](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-mwaa-ai-agent-skills/) for writing, debugging, testing, and upgrading Airflow workflows (October 15). It works with Claude Code, Codex, Cursor, and Kiro. The skills are free under Apache-2.0. **Cost note:** you pay for the AWS resources your agent uses.

### 7. 3D: [EL4CTEO/blender-skills](https://github.com/EL4CTEO/blender-skills)

Twenty-two skills covering the whole Blender 5.2 pipeline: scene setup, hard-surface and organic modeling, retopology and UVs, PBR materials, baking, geometry nodes, rigging, animation, export, rendering, and QA. A `blender-core` skill routes each task, and the README says every script was tested in real Blender. It uses an optional Blender MCP server when one is running, and runs Blender in the background otherwise. Free, MIT. New on October 14.

## Also added to the catalog

### Standards and discovery

- [agent-sh/agnix](https://github.com/agent-sh/agnix) — A linter and language server for agent config files. It checks `SKILL.md`, `AGENTS.md`, `CLAUDE.md`, hooks, and MCP configs against 702 rules, auto-fixes what it can, and ships a GitHub Action and editor plugins. It's useful because a skill with a broken frontmatter field can fail to load without any error. Free, MIT or Apache-2.0. The README includes a sponsor placement.

### Writing and design

- [juliobsz/skills](https://github.com/juliobsz/skills) — `/awwwards` takes a one-line brief and acts as creative director, designer, and developer, then checks the finished site in a real browser before handing it back. `/jury` scores any site the way an Awwwards jury would. New on October 12, MIT.

## Platform news this week

- **Shopify launched Shop MCP and the Shop skill** (October 13). Agents can search more than a billion products and check out with Shop Pay through one MCP connection. [Changelog](https://shopify.dev/changelog/posts/add-shopping-and-shop-pay-checkout-to-any-agent-with-shop-mcp).
- **AWS consolidated its agent skills** into the Agent Toolkit for AWS and added SageMaker AI (October 13) and MWAA (October 15) skills. [AI/ML announcement](https://aws.amazon.com/about-aws/whats-new/2026/10/bring-sagemaker-ai-expertise-to-your-coding-agent/), [MWAA announcement](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-mwaa-ai-agent-skills/).
- **Prismatic moved its skills to the open format** (October 15), tested in Claude Code, Cursor, Codex, GitHub Copilot, and Antigravity, and installable with `npx skills add prismatic-io/agent-skills`. [Changelog](https://prismatic.io/docs/changelog/2026/10/15/prismatic-agent-skills/).

## Honorable mentions

- [aicodeking/leanrea](https://github.com/aicodeking/leanrea) — A single 8 KB skill offered as a lighter alternative to REA. It uses plain CLI tools and no MCP. Its README reports a benchmark where it ran 38% faster and 35% cheaper; those are the author's own numbers. New on October 17, MIT.
- [olivieropinotti/orchestrator-skill](https://github.com/olivieropinotti/orchestrator-skill) — A Claude Code skill that turns your main session into a dispatcher that hands work to subagents so the main session never blocks. New on October 17, MIT.
- [FeedHive/ai-slop-detector](https://github.com/FeedHive/ai-slop-detector) — 120 patterns that make writing read as AI-generated, with a skill for Claude Code and Codex. A good companion to [petergyang/no-ai-slop](https://github.com/petergyang/no-ai-slop) from Edition 02. New on October 12, MIT.
- [microsoft/SkillOpt](https://github.com/microsoft/SkillOpt) — A research tool that improves natural-language skills from agent trajectories, keeping an edit only when it passes validation. It's for teams that want to measure whether a skill actually helps, MIT.
- [prismatic-io/agent-skills](https://github.com/prismatic-io/agent-skills) — Official Prismatic skills for building, deploying, and troubleshooting integrations. It's niche, but it's a clean example of a vendor moving from a harness-specific plugin to the open standard.

## Left out on purpose

The skills.sh trending page is still crowded with near-identical `*/superpowers` packs from many different accounts. They aren't affiliated with [obra/superpowers](https://github.com/obra/superpowers), and none cleared the inclusion bar. The same pattern showed up around REA this week, with lookalike repos borrowing its name. A big wave of novelty skills built on a fast-food MCP was fun to see but too narrow for this list. As always, scan third-party packs before you install them ([NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector)).
