# Edition 04: Checks and balances — Week of October 26, 2026

The companion write-up for [Awesome Agent Skills](../README.md). The living catalog stays in the root README; this file keeps the narrative, cost and safety notes, the week's platform news, and honorable mentions.

**What this is:** eight additions to the catalog, seven of them featured, all with real repos and docs.  
**What this isn't:** a ranking by stars. Two picks are older tools that the week made more relevant; the rest are new since October 18.

> Install tip: most packs here install with `npx skills add owner/repo` ([skills.sh](https://www.skills.sh/)) or `gh skill install owner/repo` (GitHub CLI 2.90.0 or later). tstack installs by cloning the repo and copying `skills/` into `~/.claude/skills` or `~/.codex/skills`.

---

## Why checks and balances

On October 22, Anthropic [donated Agent Skills to the Agentic AI Foundation](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation) (AAIF), the Linux Foundation project it co-founded with Block and OpenAI and where MCP already lives. The name, logo, GitHub org, and the agentskills.io domain move with it. The specification itself didn't change. What changed is who decides what comes next, and the proposed roadmap starts with versioned releases, a formal proposal process, and security guidance for people who write and install skills.

That is the theme at ecosystem scale. This edition looks for the same thing inside single skills: a way to inspect what you install (track 1), more than one reviewer on a change (track 2), rules that a tool enforces instead of a prompt asking nicely (tracks 3 and 4), and output checked against something real before the agent calls it done (tracks 5 to 7).

## Featured tracks

### 1. Inspection: [GitHub CLI: gh skill](https://cli.github.com/manual/gh_skill)

Not new this week, but it's the most practical answer to the security half of the AAIF roadmap. `gh skill` searches, previews, installs, pins, updates, and publishes skills from any GitHub repository, and installs into the shared `.agents/skills` directory that Copilot, Claude Code, Cursor, Codex, Gemini CLI, and others read. `gh skill preview owner/repo skill` shows the files before anything lands on disk. GitHub's own [docs](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills) say skills are not verified by GitHub and recommend previewing first. Free, part of the GitHub CLI, in public preview, and it needs version 2.90.0 or later.

### 2. Review: [t3dotgg/tstack](https://github.com/t3dotgg/tstack)

The daily PR skills from t3dotgg, published October 24 and at about 1,460 stars three days later. `full-send` takes a change all the way to a merged PR: it proves the change, reviews it, files it, babysits CI and review bots, and merges. `full-stop` does the same but stops before the merge. `council` gets review from three strong models from three different providers and loops until they agree, and it reports instead of quietly substituting when a provider is unavailable. Also included: `sol-loop`, `file-pr`, `takeover`, `babysit-pr`, `modernize`, and `leaving-pr-comments`. Works in Claude Code and Codex. Free, MIT. **Requirements:** an authenticated `gh`, `python3`, and for `council` a harness that can run subagents on other providers' models. **Safety note:** `full-send` merges with nobody watching, so start with `full-stop`.

### 3. Idiom: [morganlinton/BeautifulRust](https://github.com/morganlinton/BeautifulRust)

Three skills for Rust: `rust-best-practices` for writing it, `rust-review` for reviewing it, and `rust-port` for porting code into it. The guidance is distilled from the Google Rust Style Guide, the Rust API Guidelines, Effective Rust, Rust Design Patterns, and Microsoft's Pragmatic Rust Guidelines, and the repo ships a `lints/` clippy configuration so CI enforces the rules the skills teach. Works across Claude Code, Codex, Copilot, Cursor, and Gemini CLI. Free, MIT. New on October 23.

### 4. Migrations: [ariga/atlas](https://github.com/ariga/atlas)

Ariga [shipped official Atlas agent skills](https://atlasgo.io/changelog/atlas-agent-skills) on October 13. The agent edits the desired schema, and Atlas plans the migration, lints it, and tests it before the agent reports done. There are skills for Postgres, MySQL, SQL Server, Oracle, Snowflake, Spanner, Redshift, Databricks, ClickHouse, the Kubernetes operator, and GitHub Actions. The skills also cover drift detection, Data Scripts, and Atlas Cloud status. Atlas is Apache-2.0. **Cost note:** if you use Atlas Cloud, check Ariga's pricing for the features you need.

### 5. Science: [K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)

Around since October 2025 and one of the biggest skill repos on GitHub, at about 54,700 stars. It's here because the current release has 177 validated skills plus 100+ scientific databases, covering biology, chemistry, medicine, and drug discovery. It also stopped bundling copies of Anthropic's document skills and points you to [anthropics/skills](https://github.com/anthropics/skills) instead, which is the right call. Install with `npx skills add K-Dense-AI/scientific-agent-skills` or `gh skill install K-Dense-AI/scientific-agent-skills`, and it also loads as a single Agent Plugins package. Free, MIT. **Note:** many skills call external databases and APIs that have their own terms and rate limits.

### 6. Motion: [lovisdotio/motion2code](https://github.com/lovisdotio/motion2code)

Give it a motion design video and it rebuilds it as inline SVG driven by one GSAP timeline, then checks the result frame by frame against the source until they match. The same method turns a screen recording into a real interactive site with ScrollTrigger. See the outputs in the [live gallery](https://fal-motion-in-code.vercel.app). Free, MIT. New on October 20.

### 7. Launch films: [alchaincyf/huashu-motion](https://github.com/alchaincyf/huashu-motion)

Ask Claude Code or Codex for a launch film and it reads the product, proposes three directions, writes the film, composes a score in ABC notation with marks that land on each scene, and opens an editor in your browser. Press C, click the frame that's off, type what you want, and the agent changes only that part. Every version is kept. The music and sound effects are generated locally, with no paid API. Install with `npx skills add alchaincyf/huashu-motion`. The main README is in Chinese, and there's a full [English README](https://github.com/alchaincyf/huashu-motion/blob/main/README.en.md). Free, MIT. New on October 18.

## Also added to the catalog

### Browser and testing

- **[squirrelscan/skills](https://github.com/squirrelscan/skills)** - Two skills: one to run the squirrel CLI, and `audit-website`, which audits a site against 300+ rules across SEO, performance, security, and accessibility, maps findings to code, fixes them in batches, and re-audits until it scores well. Its manifest lists a sha256 for every file, and the CLI verifies each one on install and update. The skills are MIT. **Cost note:** they need the squirrel CLI and a squirrelscan account, and the CLI uses credits, so check [squirrelscan.com](https://squirrelscan.com) for pricing.

## Platform news this week

- **Agent Skills moves to the AAIF.** Announced October 22. Anthropic says the standard is supported on more than 70 platforms, with over a million skills published and about 280 million installs. David Soria Parra and Mahesh Murag are the lead maintainers. See the [announcement](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation).
- **Cursor's Agent SDK ships with skills.** The [Cursor Agent SDK](https://cursor.com/blog/agent-sdk), released October 20, includes skills that guide coding agents through building on it, so the agent that writes your integration learns the SDK the same way it learns any other framework.
- **Signed skills from NVIDIA.** [NVIDIA/skills](https://github.com/NVIDIA/skills), already in the catalog, ships each skill with a signature and a skill card, which is the kind of provenance the AAIF security work is likely to build on.

## Honorable mentions

Promising, but either too new, too narrow, or not yet proven enough for the catalog.

- **[nschurmann/hola-ai](https://github.com/nschurmann/hola-ai)** - XP-inspired skills for building with AI without letting go of the wheel: backlog, then story, then pair. New on October 21.
- **[ethanplusai/astro-conversion-kit](https://github.com/ethanplusai/astro-conversion-kit)** - Converts a WordPress site, or any live site, into a static Astro site with URL, SEO, content, and pixel parity, then takes it through launch. New on October 22.
- **[actionow-ai/vvv](https://github.com/actionow-ai/vvv)** - Build a video template once and reuse it across coding agents: editable Remotion templates plus a skill for Claude Code, Codex, and 25+ agents. A good companion to [remotion-dev/skills](https://github.com/remotion-dev/skills). New on October 22.
- **[gokayfem/video-to-blender](https://github.com/gokayfem/video-to-blender)** - Turns a reference video, image, or idea into an editable procedural Blender node system, backed by a tested node-group library. Pairs well with [EL4CTEO/blender-skills](https://github.com/EL4CTEO/blender-skills). New on October 21.

## Left out on purpose

[daniellockyer/dstack](https://github.com/daniellockyer/dstack) got attention as another engineer's daily stack, but it has no skills in it yet. The fast-food MCP novelty wave continued, and paid skill bundles with a couple of free samples kept showing up in feeds. Lookalike `*/superpowers` packs are still crowding skills.sh trending. None of them cleared the inclusion bar. Preview before you install (`gh skill preview`), and scan third-party packs ([NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector)).
