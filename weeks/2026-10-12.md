# Edition 02: Taste and proof — Week of October 12, 2026

The companion write-up for [Awesome Agent Skills](../README.md). The living catalog stays in the root README; this file keeps the narrative, cost notes, the week's platform news, and honorable mentions.

**What this is:** twelve additions to the catalog, seven of them featured, all with real repos and docs.  
**What this isn't:** a mirror of the skills.sh leaderboard. Popularity got a project onto the shortlist; it did not get it into the list.

> Install tip: most packs here install with `npx skills add owner/repo` ([skills.sh](https://www.skills.sh/)). Several also ship as Claude Code or Codex plugins; the repo README says which.

---

## Why taste and proof

Edition 01 set the floor: format, discovery, method, and review. With that in place, the two most common complaints about agent output are that it looks and reads like every other AI output, and that nobody can say whether it actually works. This edition answers both. Tracks 1 to 5 give the agent taste across interfaces, motion, video, and prose. Tracks 6 and 7 make it show its evidence.

## Featured tracks

### 1. Taste: [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)

Anti-slop frontend skills that steer agents away from the generic SaaS template look and toward deliberate, premium interfaces. Ships a family of style skills (minimalist, industrial brutalist, redesign, brand kit, and image-generation frontends) that install individually with `--skill`. Free, MIT. The README carries sponsor placements; the skills themselves are open.

### 2. Design language: [pbakaus/impeccable](https://github.com/pbakaus/impeccable)

Started from Anthropic's `frontend-design` and went further: one skill, 24 commands (`polish`, `audit`, `critique`, `distill`, `bolder`, `quieter`, and more), a `PRODUCT.md` setup flow, and 59 deterministic detector rules for AI-generated design tells. Free, Apache-2.0. The CLI and browser extension run the deterministic rules with no LLM and no API key. Docs: [impeccable.style](https://impeccable.style).

### 3. Motion: [emilkowalski/skills](https://github.com/emilkowalski/skills)

Animation and interface-craft skills from a design engineer with Vercel and Linear experience. The premise is that agents pick the wrong small ingredients (an `ease-in` on an enter animation, a solid border where a soft shadow belongs) and those choices compound. Free, MIT.

### 4. Video: [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)

An open-source framework that renders HTML, CSS, media, and seekable animations into deterministic MP4s, with 21 published skills and a `/hyperframes` router that picks the right workflow for any "make me a video" request. One of the most-installed packs on skills.sh this week. Free, Apache-2.0; requires Node 22 or newer. Prefer `npx hyperframes skills update` for the lean core set.

### 5. Voice: [petergyang/no-ai-slop](https://github.com/petergyang/no-ai-slop)

Removes 20+ named AI writing patterns (binary contrasts, throat-clearing openers, faux-insight setups, colon reveals) while preserving your vocabulary and cadence, then lists what it changed. Also has a detect-only mode. Free, MIT.

### 6. Proof: [confident-ai/eval-skills](https://github.com/confident-ai/eval-skills)

The newest pick, launched on Show HN on October 10. Ten skills walk an agent through building evals for an AI app: capture one inspectable trace, run human-led error analysis, build datasets, calibrate graders against human judgment, run repeatable experiments, and add regression gates. Works with Claude Code, Codex, and Cursor. Free, Apache-2.0. It defaults to Confident AI's Jev for model-based graders, and you can bring your own judge. Still a small repo, included for substance rather than traction.

### 7. Audit: [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

The single-repo seed of Cloudflare's vulnerability discovery harness ([write-up](https://blog.cloudflare.com/build-your-own-vulnerability-harness)). Six phases: reconnaissance, coverage-led hunting by isolated agents, validation by a fresh verifier that tries to disprove each candidate, schema-checked findings, independent record verification, and a neutral report. Free, MIT. Pairs naturally with [trailofbits/skills](https://github.com/trailofbits/skills) from Edition 01.

## Also added to the catalog

### Coding workflows

- [twostraws/SwiftUI-Agent-Skill](https://github.com/twostraws/SwiftUI-Agent-Skill) — Modern SwiftUI guidance on APIs, design, performance, and accessibility, aimed at the mistakes LLMs actually make. Siblings cover SwiftData, Swift Concurrency, and Swift Testing. Free, MIT.

### Security and platforms

- [google/skills](https://github.com/google/skills) — Official skills plus product plugins (skills and MCP servers) for Google Cloud, BigQuery, the gcloud CLI, and more. Free skills; **cloud usage is billed by Google**. Apache-2.0.
- [microsoft/azure-skills](https://github.com/microsoft/azure-skills) — Official Azure plugin: skills for prepare, validate, deploy, diagnostics, cost, and compliance, wired to the Azure MCP Server. Free skills; **Azure usage is billed**. MIT.
- [NVIDIA/skills](https://github.com/NVIDIA/skills) — NVIDIA-verified catalog for CUDA-X, robotics, simulation, and RAG, synced daily from product repos. Needs `skills` CLI 1.5.16 or newer. Free, Apache-2.0.
- [prisma/skills](https://github.com/prisma/skills) — Prisma ORM 7 CLI reference, a v6-to-v7 upgrade guide, a MongoDB decision guide, and client API skills. Free.

## Honorable mentions

- [franzenzenhofer/big-arrow-on-the-screen](https://github.com/franzenzenhofer/big-arrow-on-the-screen) — macOS CLI plus a Claude Code and Codex skill that lets an agent draw a click-through arrow and label on your screen to show you where to click. Created October 8 and widely shared on Hacker News. macOS only, MIT.
- [phuryn/work-humanizer](https://github.com/phuryn/work-humanizer) — Takes the AI tone out of work writing without changing what it says or commits to, with published blind-judge evidence. New on October 9, MIT.
- [Tejashmakwana/motionmaxxing](https://github.com/Tejashmakwana/motionmaxxing) — A skill aimed at making agent-made videos look designed rather than templated. New on October 6, Apache-2.0.
- [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) — Viral token-saving skill and proxy that makes agents talk tersely. Useful for cost, but it changes output style, so try it on a branch first.
- [google/agents-cli](https://github.com/google/agents-cli) — CLI and skills for scaffolding, evaluating, and deploying agents on Google Cloud.

## Left out on purpose

The skills.sh trending page this week is crowded with near-identical packs published under many different `*/superpowers` and `*-skills` accounts, mostly for image, video, and social automation. They are not affiliated with [obra/superpowers](https://github.com/obra/superpowers), and none cleared the inclusion bar. Treat that pattern with caution, and scan before you install ([NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector)).
