# Edition 05: Show your work — Week of November 2, 2026

The companion write-up for [Awesome Agent Skills](../README.md). The living catalog stays in the root README; this file keeps the narrative, cost and safety notes, the week's platform news, and honorable mentions.

**What this is:** eight additions to the catalog, seven of them featured, all with real repos and docs.  
**What this isn't:** a ranking by stars. Three picks are older repos that the week made more relevant; the rest are new since October 26.

> Install tip: most packs here install with `npx skills add owner/repo` ([skills.sh](https://www.skills.sh/)) or `gh skill install owner/repo` (GitHub CLI 2.90.0 or later). The MiniMax and Anthropic finance packs install as Claude Code plugins, and the single agent loop kit is copied into `.claude/skills` by hand.

## Why show your work

On October 22, Anthropic's Applied AI team published [Building agents: When to fold subagents into your main agent loop](https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop). Its finding from several enterprise deployments: one agent loop that loads skills and tools on demand often beat both one giant prompt and a router in front of specialist subagents, on quality, cost, and latency. The advice that matters most is how to get there. Score the system on an eval first, and only remove a subagent when the numbers say its replacement holds.

Every pick this week works the same way. Each one leaves evidence you can check: a fresh accessibility snapshot after every desktop action (track 1), an eval score before and after each change (track 2), a reviewer that sees only the diff and the test results (track 3), formula traces and balance checks in a financial model (track 4), and visual output that the agent zooms into, films, or renders in every state before it says it's done (tracks 5 to 7).

## Featured tracks

### 1. Desktop: [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop)

Vercel Labs' computer use CLI, the desktop sibling of [agent-browser](https://github.com/vercel-labs/agent-browser), had its public launch on October 31. It reads and operates desktop apps on macOS, Windows, and Linux through the OS accessibility tree, not screenshots. A snapshot returns JSON with a ref for every element the agent can act on. The agent acts on a ref, then snapshots again to check, with no pixel matching. Install with `npm install -g agent-desktop`, then add the skill with `npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop`. The [skills docs](https://agent-browser.dev/desktop/skills) cover the rest. Free, Apache-2.0. **Requirements:** Accessibility permission on macOS and `at-spi2-core` on Linux. **Safety note:** snapshots, clipboard reads, and screenshots can contain private desktop content, so keep them out of public logs. The optional JEV helper sends screen descriptions to a model provider you configure, and that provider may charge for it.

### 2. Measurement: [anthropics/single-agent-loop-kit](https://github.com/anthropics/single-agent-loop-kit)

The companion kit to the Anthropic article above. Copy its skill into your agent repo, tell Claude Code to run it, and it audits your multi-agent system first. It gives a verdict for each subagent (fold, merge, call as a tool, or keep) and stops so you can correct it. Then it works the plan one change at a time, with an eval run and a before-and-after comparison for each. The `examples/support-desk` demo has a router and six subagents, and its smoke check runs offline with no API key. Free, Apache-2.0. **Note:** it's a reference implementation that isn't maintained and isn't accepting contributions, and the scored eval runs use your own model API.

### 3. Fresh eyes: [MiniMax-AI/mcode-stack](https://github.com/MiniMax-AI/mcode-stack)

The MiniMax Code team [open-sourced](https://www.marktechpost.com/2026/10/28/minimax-open-sources-mcode-stack-agent-skills/) the workflows they use to build MiniMax Code on October 28: 17 `SKILL.md` skills and five checklists in two stacks. The standout is `independent-review`, where the reviewer gets only the diff, the requirement, and the test results, not the conversation that produced the change. Also included: `subagent-split-check` (should this task go to a subagent at all?), `tool-budget-audit`, `context-tax-audit` (what goes into context every turn), `long-command-check` (how long to wait on a long command), `long-session-check`, `trajectory-review`, and `handoff-doc`. Install the main stack in Claude Code with `claude plugin install ronny --marketplace MiniMax-AI/mcode-stack`, or in Codex with `codex plugin marketplace add MiniMax-AI/mcode-stack`. Free, MIT. **Note:** the team hasn't published evals for the skills yet.

### 4. Models: [anthropics/financial-services](https://github.com/anthropics/financial-services)

Not new, but its latest update landed October 28 and it made the rounds this week as Anthropic's open-sourced Wall Street skills. It ships ten named agents (Pitch Agent, Model Builder, GL Reconciler, Month-End Closer, and others) and the vertical plugins underneath them, with skills for comps, DCF, LBO, and three-statement models built live in Excel. It also has an Excel audit skill that traces formulas, flags hardcoded numbers, and checks that the balance sheet balances. Everything installs as a Claude Cowork plugin, through `claude plugin marketplace add anthropics/financial-services`, or as a Claude Managed Agent. Free, Apache-2.0. **Cost note:** some data connectors need paid data subscriptions. **Safety note:** the repo says every output is analyst work product staged for human sign-off, not investment advice.

### 5. Explainers: [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy)

Not new this week (the repo was created October 8), but it's now one of the most-starred skills of the month, at about 24,000 stars, and earlier editions missed it. Ask for a figure that explains a technical idea and Anatomy invents a physical machine whose workings are the concept. A cache key becomes a pin-tumbler lock that only turns when every pin matches. It builds the machine as an interactive isometric figure in SVG, with optional WebGL and 3D, and checks its own work by zooming in on every joint. Every number on the figure comes from the same small model that moves its parts. Install with `npx skills add wheresryan22/anatomy -g`. It runs in Claude Code, Codex, Antigravity, OpenCode, and MiniMax Code, needs no API keys, and uses only Node's built-in modules. See the [gallery](https://skills.wheresryan.sh/anatomy). Free, MIT. **Note:** a detailed figure takes a long session.

### 6. Product stills: [benjitaylor/skills: Stageshow](https://github.com/benjitaylor/skills)

Benji Taylor's [Stageshow](https://benji.org/stageshow), released October 31, is a skill and a small React kit for product illustrations: stills, cursor demos, bento grids, and phone flows built as real components. It ships gold examples, nine visual styles, and labeled bad-and-good teaching pairs, plus scripts that film the result and check its layout and motion. Install with `npx skills add benjitaylor/skills --skill stageshow`. Free; the license file is in the `stageshow/` folder. **Note:** the kit needs Node 20.19 or later, and the README is clear that no automated check replaces watching the motion yourself.

### 7. Interface polish: [jakubkrehel/skills](https://github.com/jakubkrehel/skills)

Fourteen Markdown skills from design engineer Jakub Krehel, split by discipline: typography, colors, accessibility against WCAG 2.2, layout, interface writing, and UI polish, plus `better-interface`, which returns one ranked report across all of them. Several plug into daily work. `interface-review` checks a branch or PR for interface regressions, `break` renders a component under every scenario that can reach it, and `state-machine` renders every state with mock data and a switcher. Around since July and still updated, with commits as recent as November 2, it's now past 10,000 stars. Install with `npx skills add jakubkrehel/skills`. Free, MIT.

## Also added to the catalog

### Writing and design

- **[gokayfem/shader-skills](https://github.com/gokayfem/shader-skills)** - GLSL and Shadertoy skills with 186 functions across 20 modules (SDF raymarching, noise, terrain, water, clouds), a bundler that resolves dependencies into one file, and a checker that catches WebGL1 leftovers and compiles with `glslangValidator`. Version 2.0.0 shipped October 23. Targets WebGL2 and GLSL ES 3.00, not HLSL or Unity. Install with `npx skills add gokayfem/shader-skills`. Free, MIT.

## Platform news this week

- **One loop, many skills.** Anthropic's Applied AI team says subagents should earn their place: fold them into skills and tools, and keep one only for parallel work or when it needs a fresh context. Read the [article](https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop), then try the [kit](https://github.com/anthropics/single-agent-loop-kit).
- **Computer use goes structured.** With [agent-desktop](https://github.com/vercel-labs/agent-desktop) next to [agent-browser](https://github.com/vercel-labs/agent-browser), Vercel Labs now covers both the browser and native apps with the same snapshot, act, and check loop.
