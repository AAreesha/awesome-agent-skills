# Edition 07: Measured, not guessed — Week of November 16, 2026

The companion write-up for [Awesome Agent Skills](../README.md). The living catalog stays in the root README; this file keeps the narrative, cost and safety notes, the week's platform news, and honorable mentions.

**What this is:** eight additions to the catalog, seven of them featured, all with real repos and docs.  
**What this isn't:** a ranking by stars. Three picks are older repos that shipped a major release or a big change since November 9; the rest were created this week.

> Install tip: most packs here install with `npx skills add owner/repo` ([skills.sh](https://www.skills.sh/)) or `gh skill install owner/repo` (GitHub CLI 2.90.0 or later). Modern Web Guidance has its own installer (`npx modern-web-guidance@latest install`), Open Code Review installs a CLI plus per-agent plugins, and Codex Security installs from the Codex plugin browser.

---

## Why measured, not guessed

Last week was about understanding before output. This week the best new skills went one step further and showed their numbers. Modern Web Guidance publishes per-agent, per-guide eval results on a public dashboard. Open Code Review benchmarks itself against 1,505 issues annotated by more than 80 senior engineers, and says plainly where it loses (recall). The game development pack ran 366 blind prompts to check that the right skill loads. Unslopovich read five million app reviews before it decided what to fix first.

The craft skills follow the same rule in a different way. STE80 Humanizer edits to a written standard and reports every change by rule number. Cinematic Skill draws every frame in code, so the same input gives the same film. When a skill says what it checks and shows how often it is right, you can decide whether to trust it before it touches your work.

## Featured tracks

### 1. Web platform: [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance)

Modern Web Guidance left preview with [v1.0.0](https://github.com/GoogleChrome/modern-web-guidance/releases/tag/v1.0.0) on November 9 (US time), and v1.0.1 followed on November 16. It is one skill backed by an offline CLI: 203 use-case guides covering 250 web platform features, from container queries and the Popover API to autofill forms and on-device AI APIs. The agent searches for the guide that fits the task and pulls only that guide into context. New in 1.0: `legacy-scan`, which finds legacy patterns in a codebase and maps each one to its modern replacement, with a matching scan, verify, report, modernize workflow in the `SKILL.md`. Search now runs on a small embedding model plus BM25, and the download dropped from 23.5 MB to 8.8 MB. The project is now stewarded by the Google Chrome, Microsoft Edge, Mozilla Firefox, and MDN teams. Install with `npx modern-web-guidance@latest install`, or try `npx modern-web-guidance@latest search "..."` first. Per-agent results are on the [eval dashboard](https://googlechrome.github.io/modern-web-guidance-src/), and the [docs](https://developer.chrome.com/docs/modern-web-guidance) live on developer.chrome.com. Free, Apache-2.0. **Note:** guides for features that shipped in only one engine in the last three months need an explicit opt-in.

### 2. Code review: [alibaba/open-code-review](https://github.com/alibaba/open-code-review)

Alibaba's internal code review assistant, open-sourced in May, gained about 2,200 stars this week and shipped three releases (v1.13.8 to v1.13.10). The design is the point: plain code decides which files to review, bundles related files, and matches review rules to each file, and the agent only does what needs judgment. On its [AACR-Bench](https://huggingface.co/datasets/Alibaba-Aone/aacr-bench) dataset (200 real pull requests from 50 repos), the project reports higher precision and F1 than a general-purpose agent with the same model, at about one ninth of the tokens, and lower recall by design. It ships plugins for Claude Code, Codex, Cursor, Kimi Code, and OpenCode, a portable agent skill, and, as of November 11, a GitHub Copilot CLI integration. Install the CLI with `npm install -g @alibaba-group/open-code-review`, then follow the plugin guide in the repo for your agent. Free, Apache-2.0. **Cost note:** `ocr review` and the `open-code-review` skill call the model you configure, at that provider's prices. The `delegate-review` command and the `open-code-review-delegate` skill use your host agent's model instead. Needs Git 2.41 or later.

### 3. Security: [openai/codex-security](https://github.com/openai/codex-security)

OpenAI's Codex Security plugin gained about 2,300 stars this week and released v0.10.0 on November 12, which resumes interrupted Standard scans, shares one cost budget across batch scans (`--max-total-cost`), and explains what stopped a blocked patch. The plugin splits security work into named skills (see the [workflow guide](https://github.com/openai/codex-security/blob/main/docs/agent-workflows.md)): `$security-scan` and `$security-diff-scan` find issues, `$deep-security-scan` repeats audits and builds on earlier findings, `$triage-finding` returns a verdict and the missing evidence for each claim, `$fix-finding` patches, and `$verify-fix` checks that a fix actually works. Every completed scan saves a report with its source evidence and coverage limits. Install it from the plugin browser in the Codex app or with `/plugins` in the Codex CLI; the same workflows run from the terminal with `npm install --global @openai/codex-security`. Apache-2.0. **Cost note:** it runs on Codex, so interactive scans use your Codex access and CI runs need an OpenAI API key; see the [plugin quickstart](https://learn.chatgpt.com/docs/security/plugin) for setup and workspace access. The optional Cloud connection is not needed for local scans. **Harness note:** the plugin targets Codex only.

### 4. Game dev: [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)

Despite the name, this is a skill pack, not a link list. [v2.0.0](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/releases/tag/v2.0.0) shipped November 11 with every skill rewritten: 79 skills across Godot, Unity, Unreal, Roblox, three.js, Phaser, PixiJS, Bevy, Defold, Ebitengine, LÖVE, and pygame, plus a router that reads your project's pinned engine version and loads only the two or three skills that fit. Each skill lists the traps agents fall into and ends with a check the agent runs itself. Code examples were run or compiled on the real toolchains for 10 of the 12 engines, and in 366 blind test prompts the right skill loaded 98.7% of the time with Claude Opus and 97.9% with Claude Haiku ([results and limits](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/evals/RESULTS.md)). If Unity's, Roblox's, or Epic's own skills are installed, the router uses them for live editor work. Install with `npx skills add gamedev-skills/awesome-gamedev-agent-skills`. Free, Apache-2.0. **Note:** the README carries sponsor banners; the skills themselves don't need any paid service.

### 5. Plain English: [Dodaios/ste80-humanizer](https://github.com/Dodaios/ste80-humanizer)

Created November 9 and past 700 stars in a week. Most humanizers only delete phrases; this one runs two passes. Pass 1 removes the 26 tells from Wikipedia's "Signs of AI writing", following [blader/humanizer](https://github.com/blader/humanizer). Pass 2 rebuilds the sentences "80% of the way to ASD-STE100", the Simplified Technical English of aircraft maintenance manuals, after an October post by Andrej Karpathy: one idea per sentence, active voice, short instructions, and plain common words where the strict dictionary would sound stiff. A Strict mode applies the full standard. It reports each edit by rule number (for example "§1, §8, S2") so you can look up why a sentence changed, and it states that getting past AI detectors is not a goal. Install with `npx skills add Dodaios/ste80-humanizer`, then call `/ste80-humanizer`. Free, MIT.

### 6. App review: [erkamyaman/unslopovich](https://github.com/erkamyaman/unslopovich)

Created November 9. The author's [study](https://github.com/erkamyaman/unslopovich/blob/main/research/README.md) read 5,008,684 reviews of 7,786 apps and found that low-rated reviews rarely mention gradients; they complain that things are broken, buttons moved, ads interrupt, or the layout breaks on their phone. So the skill checks those first: controls that moved or do nothing, AI features in the way of the task, numbers nobody measured, a website squeezed into a phone, and error states that say nothing. It has 31 detector rules, scores a screen out of 24, and works on mobile apps, web apps, and websites. Three modes: `review` (diagnosis only, no edits), `treat` (diagnose, fix, verify, before and after), and `scan`. Every report marks performance as "Not profiled" until someone profiles it. Install with `npx unslopovich`, then ask your agent for `/unslopovich review my app`. Free, MIT, no dependencies.

### 7. Film: [Moh4696/cinematic-skill](https://github.com/Moh4696/cinematic-skill)

Created November 9 and past 600 stars. Ask for "a 90 second documentary about the Wright brothers" and the agent writes the script, records a scratch voice, finds public-domain photos on Wikimedia Commons with their licences (non-free files are refused, and `credits.md` is written for you), and builds one continuous camera move over a designed world. Stamps, highlights, and counters land on the exact word the narrator says. Nothing is generated video: every frame is drawn in Python with Skia, so the film renders the same every time, and a new voice re-times the whole film. Sound effects are synthesised, so there is nothing to license. Install with `npx skills add Moh4696/cinematic-skill`, or as a Claude Code or Codex plugin. Free, MIT. **Requirements:** Python with skia-python, NumPy, and Pillow, and ffmpeg on your PATH; the final voice can be any TTS or a person.

### Writing and design

- **[obsidianmd/obsidian-skills](https://github.com/obsidianmd/obsidian-skills)** - Obsidian's agent skills, started by CEO Steph Ango and past 50,000 stars, are now published by Obsidian itself. [Release 1.1.0](https://github.com/obsidianmd/obsidian-skills/releases/tag/1.1.0) (November 11) moved the repo to `obsidianmd`, made it one plugin with Claude Code, Codex, and Cursor marketplaces, and fixed an issue that kept earlier changes from reaching existing installs. ## Platform news this week

- **Vendor packs keep growing.** [google/skills](https://github.com/google/skills) added Compute Engine and GKE troubleshooting skills, an Agent Platform autorater skill that builds eval metrics from an agent's own trajectories, and a `google-cloud-release-radar` skill. AWS [published four Amazon MWAA skills](https://aws.amazon.com/blogs/big-data/upgrading-and-troubleshooting-amazon-mwaa-with-aws-agent-skills/) for authoring, testing, debugging, and upgrading Airflow (including 2.x to 3.x) in [aws/agent-toolkit-for-aws](https://github.com/aws/agent-toolkit-for-aws), alongside new Render-to-AWS and Heroku-to-AWS migration guidance.
- **Anthropic's document skills got fixes.** [anthropics/skills](https://github.com/anthropics/skills) updated the docx, pptx, xlsx, and pdf skills on November 14 and 16, including zip handling and validator fixes. Reinstall if you copied them by hand.
- **Evidence is becoming the bar.** Four of this week's eight additions publish an eval, a benchmark, or a study, and a fifth publishes its rule list. Expect "how do you know it works?" to be the first question for new packs.

## Honorable mentions

Promising, but either too new, too narrow, or not yet proven enough for the catalog.

- **[globalmpc/backendskills](https://github.com/globalmpc/backendskills)** - Backend skills for auth, data integrity, payments, and schema changes, with a hidden-check benchmark: critical mistakes fell from 25 of 150 runs to 2 of 150. The method is honest about where the gain comes from (two tasks account for most of it), but the repo is under two weeks old with a small community.
- **[diego3g/craft](https://github.com/diego3g/craft)** - Design skills that write a brief, list every state a screen can be in, use your design system, and check their own work before showing it. Created November 15; we'll check back.
- **[backnotprop/plannotator](https://github.com/backnotprop/plannotator)** - A local browser review surface where you annotate an agent's plan or diff and send the feedback back as its next turn, with skills for Codex and Kiro. Useful, but it is mainly an app with hooks rather than a skill pack.

## Left out on purpose

GitHub search this week was flooded with dozens of near-identical "GitHub Copilot app" repos under throwaway accounts, all created November 14 and tagged as agent skills. They are not from GitHub, and none cleared the inclusion bar. The skills.sh board was again led by media and automation skills republished under several organizations with matching install counts. Preview before you install (`gh skill preview`), and scan third-party packs ([NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector)).
