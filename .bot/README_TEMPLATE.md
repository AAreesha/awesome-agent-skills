## About

**Awesome Agent Skills** is an automatically researched, human-taste-filtered directory of agent skills — reusable instruction packs, plugins, hooks, and workflows that make coding agents sharper.

- **Cadence:** refreshed every week
- **Scope:** skills / skill packs / agent plugins (not general AI tooling)
- **Bar:** public, installable, documented, actually useful

## Contributing

Contributions welcome! Please open a PR that:

1. Adds **one skill per PR** (or a clearly related set)
2. Follows the entry format: `**[Name](url)** - description. \`tags\``
3. Places the entry in the right category (alphabetically within the section)
4. Avoids duplicates and marketing-only pages

See the [inclusion criteria](#legend) above. For larger structural changes, open an issue first.

```bash
# Suggest an entry (EXAMPLE — replace OWNER/REPO)
gh issue create --title "skill: my-cool-skill" --body "URL: https://github.com/org/repo"
```
